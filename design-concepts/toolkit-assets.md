## Generation prompts

Each generation used the approved mockup as its sole reference and the following shared prompt, followed by the corresponding asset prompt:

> Use case: compositing / background-extraction. Reference image is an APPROVED HaikaiTech website mockup. Extract/recreate only the specified decorative object as a production-quality isolated raster website asset on a GENUINELY TRANSPARENT BACKGROUND with alpha. Preserve the mockup's fine matte painted clay grain, rounded sculpted edges, navy/blueprint #1E3A8A and #16202A, warm cream paper #FDFBF7 and small yellow #F4D35E accents. Soft local transparent contact shadow only. No page background, engineering dots, UI, buttons, headings, scribbles, surrounding grid, unrelated objects, labels outside the objects, watermark, checkerboard, or white rectangle. Entire object visible with modest even 4% transparent padding. This is conceptual stationery, no client/business data. Faithfully match reference material and silhouette.
